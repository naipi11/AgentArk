# AgentArk M0 threat model

## Assets and boundaries

- Raw vendor records, encrypted CAS objects, SQLCipher index, dataset keys, and
  sanitized public projections are distinct assets.
- Vendor files cross the `SourceAdapter` boundary read-only; app orchestration
  crosses into CAS/index only after capture.
- Tauri crosses into the app only through five typed query commands.

## Threats and controls

| Threat | Control and evidence | Typed outcome |
| --- | --- | --- |
| Hostile JSONL, Markdown, HTML, unknown items | `crates/adapters/codex/tests/normalization.rs`, `crates/security/tests/secret_projection.rs` | quarantine/retryable; no hidden reasoning entity |
| Concurrent append/replacement | `crates/adapters/codex/tests/filesystem_capture.rs` and stable-prefix splitter | retryable `incomplete-final-record` or `source-changed` |
| Traversal, UNC, device, ADS, symlink, junction/reparse | `crates/security/tests/path_policy.rs` and capability-relative open | typed forbidden-path error |
| Source DB/WAL mutation | adapters enumerate only JSONL and tests compare tree digests | no write operation |
| Credential files/transcript secrets | explicit file allowlist and `SecretScanner` canaries | redacted projection; credential files never opened |
| Stolen dataset/CAS/index tamper | OS-wrapped keys, SQLCipher, XChaCha20-Poly1305, `m0_end_to_end.rs` | authentication/hash verification failure |
| App Server drift/hostile JSON-RPC | pinned schema/fingerprint, bounded JSON lines, read-only method allowlist | quarantine or typed protocol error |
| Tauri XSS/navigation/IPC expansion | CSP, React text nodes, command registry unit test | no HTML interpretation or external navigation |
| Retry duplication/partial publication | transactional index ingest, idempotent keys, scan manifest counts | partial report or failed scan; stale retained sessions |
| Network egress | local stdio process transport and `ci/network-silence.sh` | no intentional network request |

## Residual risks

The local OS account and keyring remain trusted for M0. App Server semantic
coverage is pinned to the recorded Codex schema; unknown versions remain
quarantined until a reviewed compatibility entry is added.
